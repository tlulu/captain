# Captain 

A Kubernetes deployment dashboard built with Axum and React.

![Captain Dashboard](./captain.gif)

### Running the App

1. **Start the server:**
   ```bash
   cargo run
   ```

2. **Start the dashboard:**
   ```bash
   cd src/web/captain
   npm install
   npm run dev
   ```

3. **Start client traffic:**
   ```bash
   ./client.sh
   ```
